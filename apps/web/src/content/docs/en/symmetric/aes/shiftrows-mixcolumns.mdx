## Spreading every byte everywhere

SubBytes scrambles bytes but never moves them. The **diffusion layer** fixes that in two moves:

- **ShiftRows** rotates row `r` of the state left by `r` positions: offsets 0, 1, 2, 3 (FIPS 197, §5.1.2).
- **MixColumns** replaces each column by a fixed linear combination of its four bytes (§5.1.3).

ShiftRows sends the four bytes of one column into four *different* columns; MixColumns then lets
each byte affect its whole column. After two rounds every output byte depends on every input byte.

## The MixColumns matrix

Each column is multiplied by a circulant matrix over GF(2⁸):

<Formula caption="FIPS 197, Equation 5.6. Multiplication is in GF(2⁸), addition is XOR.">
{`┌ s'₀ ┐   ┌ 02 03 01 01 ┐ ┌ s₀ ┐
│ s'₁ │ = │ 01 02 03 01 │ │ s₁ │
│ s'₂ │   │ 01 01 02 03 │ │ s₂ │
└ s'₃ ┘   └ 03 01 01 02 ┘ └ s₃ ┘`}
</Formula>

`02·a` is **xtime**: shift left, XOR `1B` on overflow. `03·a = xtime(a) ⊕ a`. Worked first byte:

<Formula>
{`02·d4 ⊕ 03·bf ⊕ 01·5d ⊕ 01·30
=  b3  ⊕  da   ⊕  5d   ⊕  30   = 04`}
</Formula>

<WhyBox constant="{02 03 01 01}" title="MDS matrix, branch number 5">
  The matrix is **MDS**: for every non-zero input column, the non-zero input bytes plus non-zero output
  bytes number at least **5** — the maximum for 4 bytes. Together with ShiftRows this “wide trail”
  forces at least 25 active S-boxes in any 4-round trail. The small entries 01, 02, 03 keep it cheap.
</WhyBox>

</LessonSection>

<LessonSection part="memory">

## Fast in software

Implementations rarely multiply matrices byte by byte. Table-based code merges SubBytes, ShiftRows
and MixColumns into four 1 KiB **T-tables**; hardware performs the whole round in one instruction.
See [Memory & hardware](../memory-and-hardware/).

</LessonSection>

<LessonSection part="break">

## Remove ShiftRows

Without ShiftRows, the bytes of one column never leave that column. AES collapses into **four
independent 32-bit ciphers**: change one plaintext byte and only one ciphertext column changes. An
attacker can then tabulate or attack each column separately — a 2³² problem instead of 2¹²⁸. A lab
toggle for this experiment follows in a later milestone.

</LessonSection>

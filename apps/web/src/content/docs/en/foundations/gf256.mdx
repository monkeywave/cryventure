## A byte is a polynomial

AES reads the bits b₇…b₀ of a byte as polynomial coefficients over GF(2), the field with only 0
and 1 (FIPS 197, §4). So `{57}` = `0101 0111` stands for x⁶ + x⁴ + x² + x + 1; FIPS 197
writes such field elements in braces.

- **Addition** adds coefficients mod 2, which is **XOR**: `{57} ⊕ {83} = {d4}` (FIPS 197, §4.1).
- **Multiplication** (`•`) multiplies the polynomials, then reduces modulo the **irreducible
  polynomial** m(x) = x⁸ + x⁴ + x³ + x + 1 = `{01}{1b}` (FIPS 197, §4.2).

The 256 bytes form the **finite field GF(2⁸)**: you can add, multiply and — except by `{00}` —
divide.

## xtime, reduction and the inverse

Multiplying by x (the byte `{02}`) is a left shift. If bit 7 was set, the result has an x⁸ term,
and x⁸ ≡ x⁴ + x³ + x + 1 (mod m(x)). So you XOR in `{1b}` (FIPS 197, §4.2.1):

<Formula caption="xtime, FIPS 197 §4.2.1, and the xtime chain of {57}.">
{`xtime(b) = (b ≪ 1) ⊕ (b₇ ? {1b} : {00})       (keep the low 8 bits)
{57} → {ae} → {47} → {8e} → {07} → {0e} → {1c} → {38}     ({57}•x⁰ … {57}•x⁷)
{57} • {83} = {57}•x⁰ ⊕ {57}•x¹ ⊕ {57}•x⁷ = {57} ⊕ {ae} ⊕ {38} = {c1}`}
</Formula>

Any product is a XOR of such shifted copies, one per set bit of the second factor.

<WhyBox constant="0x11B" title="x⁸ + x⁴ + x³ + x + 1">
  The modulus must be **irreducible**: no product of two lower-degree polynomials. Otherwise two
  non-zero bytes could multiply to `{00}`, and those bytes would have no inverse. FIPS 197, §4.2
  picks this degree-8 irreducible polynomial.
</WhyBox>

**Inverse.** The 255 non-zero bytes form a group under `•`, so a²⁵⁵ = `{01}` (Lagrange) and
a⁻¹ = a²⁵⁴. Example: `{53}⁻¹ = {ca}`. AES defines `{00}⁻¹ = {00}` (FIPS 197, §5.1.1). This inverse
is the heart of the AES S-box: [Deriving the S-box](../../symmetric/aes/sbox-derivation/).

## Shifts, masks and tables

In code, `xtime` is a shift plus a conditional XOR. The branch-free form
`(b << 1) ^ (0x1B & -(b >> 7))` takes the same time for every byte; a version with `if` may not.
Many implementations replace multiplication with 256-byte log/antilog tables, or precompute the
S-box and MixColumns as tables. Those lookups are indexed by secret bytes and can leak through the
cache. The [AES memory & hardware](../../symmetric/aes/memory-and-hardware/) page shows the
consequences and how AES-NI avoids them.

<Formula caption="Branch-free xtime in C.">
{`uint8_t xtime(uint8_t b) { return (uint8_t)((b << 1) ^ (0x1B & -(b >> 7))); }`}
</Formula>

<Lens level="cryptographer">

Log tables need a **generator**. m(x) is not primitive: `{02}` has order 51, while `{03}` generates
all 255 non-zero bytes. FIPS 197, §4.2 computes inverses with the **extended Euclidean algorithm**:
since m(x) is irreducible, gcd(a(x), m(x)) = 1 for every a ≠ 0, so b(x) with a(x)b(x) ≡ 1 always
exists.

</Lens>

</LessonSection>

<LessonSection part="break">

## Mallory picks a reducible modulus

Mallory swaps m(x) for the simpler x⁸ + 1. But x⁸ + 1 = (x + 1)⁸ over GF(2), so it is reducible.
Then `{03} • {ff}` = (x + 1)(x⁷ + … + 1) = x⁸ + 1 ≡ `{00}`: two non-zero bytes multiply to zero, and
`{03}` has no inverse (Lidl & Niederreiter, Ch. 1, Thm 1.61). The S-box needs an inverse for every
non-zero byte (FIPS 197, §5.1.1), and MixColumns needs one to be undone (FIPS 197, §5.1.3). With an
irreducible m(x), GF(2⁸) gives AES both, on exactly the 256 values a byte can hold.

</LessonSection>

<CheckQuestion number={1} question="What is {57} + {83} in GF(2⁸)?" options={['{da}', '{d4}', '{c1}', '{01}{d4}']} answer={1}>
  Addition is coefficient-wise mod 2, i.e. XOR: `{57} ⊕ {83} = {d4}` (FIPS 197, §4.1). `{da}` is the
  integer sum, and `{c1}` is the product.
</CheckQuestion>

<CheckQuestion number={2} question="What is xtime({80})?" options={['{00}', '{01}{00}', '{1b}', '{80}']} answer={2}>
  Shifting `{80}` left drops bit 7 and leaves `{00}`. Bit 7 was set, so the x⁸ term is reduced by XOR
  with `{1b}`: the result is `{1b}` (FIPS 197, §4.2.1).
</CheckQuestion>

<CheckQuestion

  With a reducible modulus, non-zero bytes can multiply to `{00}` and then have no inverse (FIPS 197,
